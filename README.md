# ☕Coffee-Shop-Data-Analysis-Using-Excel 
## 📌 Project Summary

This project is an interactive Coffee Shop Sales Dashboard developed entirely in Microsoft Excel. The dashboard transforms raw transactional sales data into meaningful business insights using Pivot Tables, Pivot Charts, Slicers, and Excel formulas.

The objective of this project is to help business owners understand customer purchasing behavior, identify sales trends, monitor store performance, and make data-driven decisions through an easy-to-use interactive dashboard.

Users can dynamically filter the dashboard using Month and Day slicers, allowing quick analysis of sales performance across different time periods.
